# 브릿지 커피 홍보물 자동 만들기

매장 사진과 가게 정보를 넣고 한 번 실행하면, 인스타그램용 사진과 채널별 홍보 문구를 만들어 주는 프로그램입니다.

## 하는 일

**사진**
- `자료` 폴더의 jpg, png 사진을 모두 1080 x 1080 정사각형으로 변환합니다.
- 사진 가운데를 기준으로 자르며, 사진이 찌그러지지 않습니다.
- 오른쪽 아래에 로고를 흰색으로 작게 넣습니다. (가로 15%, 가장자리에서 40px)
- `완성` 폴더에 `날짜_번호.jpg` 형식(예: `20261021_01.jpg`)으로 저장합니다. 원본 사진은 건드리지 않습니다.

**홍보 문구** (`완성/홍보문구.txt`)
- 인스타그램용: 감성형 / 정보형 / 이벤트형 3가지 + 해시태그 10개
- 네이버 블로그용: 1000자 안팎의 긴 글 (해시태그 없음)
- 카카오톡 단골 공지용: 3줄 이내, 존댓말
- 문구는 사장님이 쓴 글(`자료/내 말투.txt`)의 말투에 맞춰 "~습니다"체, 짧은 문장으로 만듭니다.
- 문구는 정해진 틀에 `자료/가게 정보.txt`의 내용을 끼워 넣는 방식이며, 외부 서비스나 API 키가 필요 없습니다. 가게 정보에 없는 내용은 지어내지 않습니다.

## 폴더 구성

```
홍보자동화/
├─ 사진변환.py      사진 변환 + 문구 생성 프로그램 (메인)
├─ 실행.bat         더블클릭으로 실행하는 파일
├─ 브릿지.ico       바탕화면 바로가기용 아이콘
├─ 사용설명서.txt   비개발자용 사용 설명서
├─ CLAUDE.md        Claude Code 작업 규칙
├─ 자료/            [입력] 사진, 로고.png, 가게 정보.txt, 내 말투.txt
└─ 완성/            [결과] 변환된 사진, 홍보문구.txt
```

## 필요한 것

- Windows
- Python 3.12 이상
- Pillow (이미지 처리 라이브러리)

```
pip install Pillow
```

## 사용 방법

1. `자료` 폴더에 이번 주 사진을 넣습니다. (지난주 사진은 옮겨 두세요. 폴더 안의 사진을 모두 변환합니다.)
2. `자료/가게 정보.txt`의 "이번 주 홍보할 것"을 고칩니다.
3. `실행.bat`을 더블클릭하거나 아래 명령어를 실행합니다.

```
python 사진변환.py
```

4. `완성` 폴더에서 결과를 확인합니다.

자세한 순서와 문제 해결 방법은 [사용설명서.txt](사용설명서.txt)를 참고하세요.

## 가게 정보.txt 형식

```
가게 이름: 브릿지 커피
위치: 광주 북구 비엔날레 지구
가게 특징: 직접 로스팅하는 스페셜티 커피, 조용한 1인 좌석 많음
주 고객층: 30~40대 직장인, 근처 사무실 손님

이번 주 홍보할 것:
- 신메뉴 '흑임자 라떼' 5,500원, 국산 흑임자를 직접 갈아서 넣음, 고소하고 달지 않음
- 오전 11시 이전 방문 시 아메리카노 500원 할인
```

- 왼쪽 항목 이름(`가게 이름:` 등)은 바꾸지 않고, 콜론(`:`) 오른쪽만 수정합니다.
- 신메뉴 줄은 `'메뉴이름' 가격, 특징, 특징` 형태로 씁니다. 메뉴 이름은 작은따옴표로 감쌉니다.
- 행사·할인 줄은 따옴표 없이 한 줄로 씁니다.
